Palette

Navy is the structural colour: headers, hero grounds, rules, table heads. Warm red is the signal — one primary action per view, kickers, the active tab marker. The tints exist for fills and quiet chrome, never for text.

Rule

Red never fills a large area except one poster-scale statement per page. Body copy is never set in red or in a tint — use ink #201e1d, #3a3838 or #605d5d.

02

Type scale

One family, four weights: 400 for prose, 500 for labels and interface text, 600 for headings, 700 only for the wordmark. Display sizes take a slight negative tracking; small uppercase labels take wide positive tracking. Figures in tables, scores and stats set tabular.

03

Layout and rules

Page gutter

48px on desktop, 20px on mobile. Every section starts at the same left edge — headings, copy, tables and cards align to it with no indents.

Dividers

2px navy between major sections and above table heads. 1px #d7d3d3 for structural edges, 1px #eae7e7 between table rows. Never soften a 2px rule into whitespace.

Grids and gaps

Equal-width cells. Card grids use a 1px gap on a #d7d3d3 background so the gap reads as a rule; free-standing groups use 20 or 26px.

Kicker, heading, copy

Every page opens with a red uppercase kicker, a 40 to 62px heading, then copy at a 74ch measure. That triad is the signature — keep it on new pages.
